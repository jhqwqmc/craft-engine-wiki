# Minecraft webfont

`minecraft.woff2` is the Minecraft 1.8.9 font by the Hypixel SkyBlock Wiki Team,
used without modification under CC BY-SA 4.0. See `minecraft-LICENSE.md`.

Source: https://github.com/skyblock-wiki/wiki-assets/blob/6fbf51a23f3a46518948bf2c983280a82dbc9c26/fonts/minecraft/1.8.9/Minecraft.woff2

Author: https://hypixelskyblock.minecraft.wiki/

`minecraft-zh.woff2` contains the Chinese glyphs used by the recipe examples,
subset from `sparrow-ui-wiki/src/fonts/unifont.full.otf`. It is used under
SIL OFL 1.1; see `unifont-LICENSE.txt`. Other Chinese glyphs fall back to the
browser's monospace font.
