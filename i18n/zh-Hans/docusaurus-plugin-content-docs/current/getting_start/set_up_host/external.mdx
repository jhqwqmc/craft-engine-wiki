---
title: 外部托管
id: external
---

```yaml
resource-pack:
  delivery:
    hosting:
      - type: external
        url: ""
        uuid: "" # 可选
        sha1: "" # 可选
```

:::info

将资源包托管在外部服务器上。  
这可以避免资源包占用你自己服务器的带宽。

通常，在你将资源包上传到托管平台后，它会提供给你以下信息：

- URL（资源包下载链接）
- UUID（可选）
- SHA1（可选）

将这三个选项填入配置即可。

:::

:::caution

为确保玩家始终收到最新版本，需要手动定期更新外部托管的资源包。

:::
