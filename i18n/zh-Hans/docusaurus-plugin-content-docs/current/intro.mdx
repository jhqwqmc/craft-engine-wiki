## 什么是 CraftEngine

CraftEngine 无需客户端模组，即可为 Minecraft 服务器添加自定义方块、物品、家具和配方。所有内容均由服务端运行，并通过资源包分发给玩家。

你只需在 YAML 配置文件中定义内容，方块注册、模型生成、贴图打包和资源包推送等工作均由 CraftEngine 完成。

:::info

CraftEngine 提供完整的方块行为 API，可以像在 Forge 或 Fabric 中一样注册自定义方块行为。熟悉模组开发的开发者应该很快就能上手。建议使用 [PaperWeight](https://github.com/PaperMC/paperweight) 作为开发依赖。

:::

## CraftEngine 是如何工作的

CraftEngine 没有局限于传统的 Bukkit API 实现，而是采用了不同的技术路线：

- **服务端模组化**——创建突破原版 Minecraft 方块数量上限的全新方块
- **类似 ViaBackwards 的转换机制**——将新方块转换为玩家客户端能够识别的方块格式
- **真正的方块注册**——注册的是实际方块，不是虚假占位。数据包、世界生成和原版机制均能正确运作

对技术细节感兴趣？完整源码在 [GitHub](https://github.com/Xiao-MoMi/craft-engine)。
