---
title: 💽 唱片机曲目
id: jukebox_song
---

:::caution

Minecraft 注册表在完成注册后不可修改，因此更新唱片机曲目后需要重新进入服务器才能生效。

:::

```yaml
jukebox_songs:
  default:credits_music:
    sound: minecraft:music.credits
    length: 100.0  # 音乐时长（秒）
    description: "Credits"  
    comparator_output: 15
    range: 32
```

为物品添加 `minecraft:jukebox_playable` 组件，即可将其设为可播放的唱片：

```yaml
items:
  default:music_stick:
    material: stick
    data:
      jukebox_playable: default:credits_music
```

自定义音效的配置方法请参阅[音效](sound.mdx)。
