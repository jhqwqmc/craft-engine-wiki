## 概览

家具是 CraftEngine **基于实体的装饰系统**。与必须对齐网格的原版方块不同，家具使用展示实体，可以用像素级精度控制位置、旋转、缩放和对齐方式。这些实体由 CraftEngine 统一管理，不会加入常规实体 tick 列表，因此运行开销低于直接使用原版展示实体。

## 结构速览

每个家具都遵循同样的结构。每个选项回答关于家具的一个问题：

```yaml
furniture:                # 配置段    ——  可以写在 configuration 下的任意配置文件中
  default:my_furniture:   # 家具 ID   ——  其他配置可通过 default:my_furniture 引用
    variants:             # 家具变体  ——  必填  → 外观元素、碰撞箱和座位
      ...
    settings:             # 家具设置  ——  可选  → 基本属性是什么（音效、击打次数等）
      ...
    behaviors:            # 家具行为  ——  可选  → 有什么行为（存储、物品展示等）
      ...
    loot:                 # 战利品表  ——  可选  → 被破坏时掉落什么
      ...
    events:               # 事件     ——  可选  → 对玩家交互的反应（放置、破坏……）
      ...
```
只有 `variants` 为必填项，其他部分均可按需添加。

## 快速上手

### 1. 最简家具

一个变体、一个元素和一个碰撞箱，就能组成可用的家具：

```yaml
furniture:
  default:my_chair:
    variants:
      ground:
        elements:
          - item: default:my_chair_model   # 要显示的物品模型
        hitboxes:
          - position: 0,0,0                # 相对于原点的碰撞箱位置
```

### 2. 调整基础属性

添加 `settings`，可以设置放置、破坏时的音效，以及破坏家具所需的击打次数：

```yaml
furniture:
  default:my_chair:
    settings:
      item: default:my_chair               # 家具对应的物品 ID（用于按鼠标中键选取物品）
      hit_times: 3                         # 破坏所需击打次数（默认为 0 = 瞬间破坏）
      sounds:
        break: minecraft:block.bamboo_wood.break
        place: minecraft:block.bamboo_wood.place
        hit: minecraft:block.bamboo_wood.hit
    variants:
      ground:
        elements:
          - item: default:my_chair_model
        hitboxes:
          - position: 0,0,0
```

### 3. 加上座位和战利品

添加座位位置后，玩家便可以坐下；再配置战利品表，即可让家具被破坏时掉落正确的物品：

```yaml
furniture:
  default:my_chair:
    settings:
      item: default:my_chair
      hit_times: 3
      sounds:
        break: minecraft:block.bamboo_wood.break
        place: minecraft:block.bamboo_wood.place
        hit: minecraft:block.bamboo_wood.hit
    variants:
      ground:
        elements:
          - item: default:my_chair_model
            translation: 0,0.5,0             # 向上半格
        hitboxes:
          - position: 0,0,0
            type: shulker                    # shulker = 硬碰撞箱
            peek: 100
            blocks_building: true
            interactive: true
            interaction_entity: true
            seats:
              - 0.5,0.3,0                   # 座位位置
    loot:
      pools:
        - rolls: 1
          entries:
            - type: furniture_item
              item: default:my_chair
```

## 将家具和物品绑定到一起

家具与物品是两个独立的配置对象。要让物品能够放置家具，需要为其添加[🪑 家具物品](../configuration/item/behaviors/furniture_item.mdx)行为，并让 `furniture` 指向家具 ID：

```yaml
items:
  default:my_chair:
    behavior:
      type: furniture_item
      rules:
        ground:
          rotation: four                    # 锁定旋转为 90° 的倍数
          alignment: center                 # 对齐到方块中心
      furniture: default:my_chair           # → 此物品放置的家具 ID
```

`furniture` 也可以直接内联**完整的家具配置**，适合将物品和家具写在同一处：

```yaml
items:
  default:my_chair:
    behavior:
      type: furniture_item
      rules:
        ground:
          rotation: four
          alignment: center
      furniture:
        settings: ...
        variants: ...
        loot: ...
```

:::tip
家具物品的变体

普通的[🪑 家具物品](../configuration/item/behaviors/furniture_item.mdx)会将家具放在玩家点击的方块表面。
要在水或熔岩上放置，需使用[🌊 液体碰撞家具物品](../configuration/item/behaviors/liquid_collision_furniture_item.mdx)。
:::
