## 概览

自定义方块定义在[配置文件](../configuration#简介)的 `block` 或 `blocks` 段中。每个条目都使用 `命名空间:路径` 作为唯一 ID（如 `default:palm_log`）；命名空间和路径不能包含中文。其余配置按需组合即可。

只有 `state` 或 `states` 为必填项，其他部分均可按需添加。

## 结构速览

每个方块都遵循同样的结构。每个选项回答关于方块的一个问题：

```yaml
blocks:                 # 配置段    ——  可以写在 configuration 下的任意配置文件中
  default:my_block:     # 方块 ID   ——  其他配置可通过 default:my_block 引用
    state:              # 方块状态  ——  必填   → 外观、模型和碰撞箱
      ...
    settings:           # 方块设置  ——  可选   → 基本属性是什么（硬度、音效、亮度、标签）
      ...
    behavior:           # 方块行为  ——  可选   → 有什么行为（生长、下落、存储、蔓延……）
      ...
    loot:               # 战利品表  ——  可选   → 被破坏时掉落什么
      ...
    events:             # 事件      ——  可选   → 对玩家交互的反应（放置、破坏……）
      ...
```

## 快速上手

### 1. 最简方块

一个状态和纹理，就是一个完整可用的方块：

```yaml
blocks:
  default:my_block:
    state:
      auto_state: note_block                       # 让插件自动选一个视觉状态
      model:
        texture: "minecraft:block/custom/my_block" # 单张纹理 → cube_all 模型
```

### 2. 设置基本属性

添加 `settings`，为方块设置与[石头](https://zh.minecraft.wiki/w/%E7%9F%B3%E5%A4%B4)相似的音效、硬度和挖掘工具：

```yaml
blocks:
  default:my_block:
    state:
      auto_state: note_block
      model:
        texture: "minecraft:block/custom/my_block"
    settings:
      hardness: 1.5
      resistance: 6.0
      is_suffocating: true
      is_redstone_conductor: true
      instrument: basedrum
      map_color: 11
      sounds:
        break: minecraft:block.stone.break
        step: minecraft:block.stone.step
        place: minecraft:block.stone.place
        hit: minecraft:block.stone.hit
        fall: minecraft:block.stone.fall
      correct_tools:
        - minecraft:wooden_pickaxe
        - minecraft:stone_pickaxe
        - minecraft:iron_pickaxe
        - minecraft:golden_pickaxe
        - minecraft:diamond_pickaxe
        - minecraft:netherite_pickaxe
      tags:
        - minecraft:mineable/pickaxe
```

### 3. 指定行为

添加 `behavior` 可以赋予方块特定行为。以下示例让它成为可以用斧剥皮的原木：

```yaml
blocks:
  default:my_block:
    state:
      auto_state: note_block
      model:
        texture: "minecraft:block/custom/my_block"
    settings:
      hardness: 1.5
      tags:
        - minecraft:mineable/axe
        - minecraft:logs
    behavior:
      type: strippable_block
      stripped: default:stripped_my_block
```

可以继续按需组合其他配置：`loot` 控制掉落物，`events` 处理交互，[`entity_renderer`](./block/states/entity_renderer) 则可以在 `state` 中配置自定义渲染。各部分彼此独立。

## 将方块和物品绑定到一起

方块与物品是两个独立的配置对象，需要显式建立关联：

### 方块侧配置

在方块配置中指定对应物品，主要用于按[**鼠标中键**](https://zh.minecraft.wiki/w/%E6%8E%A7%E5%88%B6#%E9%80%89%E5%8F%96%E6%96%B9%E5%9D%97)选取方块，以及查询方块对应的物品。此项可选，默认使用自定义方块自身的 ID。

```yaml
blocks:
  default:my_block:
    state: ...
    settings:
      item: default:my_block    # 该方块映射到的物品 id
```

### 物品侧配置

要让玩家能够**右键放置**方块，需要为物品添加[🧱 方块物品](item/behaviors/block_item)行为，并让 `block` 指向方块 ID：

```yaml
items:
  default:my_block:
    behavior:
      type: block_item
      block: default:my_block   # 该物品放置的方块

blocks:
  default:my_block:
    state: ...
    settings: ...
```

`block` 也可以**直接内联完整的方块配置**，适合将物品与方块写在同一处：

```yaml
items:
  default:my_block:
    behavior:
      type: block_item
      block:
        state: ...
        settings: ...
        loot: ...
```

:::tip
方块物品的变体

普通[🧱 方块物品](item/behaviors/block_item)会在玩家点击的位置放置方块。
当需要特殊放置规则时，CraftEngine 提供了以下变体，它们都接受同样的 `block` 选项：[⬇️ 天花板方块物品](./item/behaviors/ceiling_block_item.mdx)、[🧱 墙面方块物品](./item/behaviors/wall_block_item.mdx)、[⬆️ 地面方块物品](./item/behaviors/ground_block_item.mdx)、[2️⃣ 双层方块物品](./item/behaviors/double_high_block_item.mdx)、[🔢 多层方块物品](./item/behaviors/multi_high_block_item.mdx)、[🌊 液体碰撞方块物品](./item/behaviors/liquid_collision_block_item.mdx)。
:::
