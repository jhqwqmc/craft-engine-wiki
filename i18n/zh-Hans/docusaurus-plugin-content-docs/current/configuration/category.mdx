---
title: 📂 分类
id: category
---

分类用于在 `/ce` 物品浏览器中整理物品。

## 基础配置

```yaml
categories:
  default:palm_tree:
    name: "<!i><green>棕榈树</green>"
    lore: []
    icon: default:palm_log
    priority: 1
    hidden: false
    conditions:
      - type: permission
        permission: category.default.palm_tree
    source:
      type: list
      list:
        - default:palm_sapling
        - default:palm_leaves
        - default:palm_log
```

| 字段 | 默认值 | 说明 |
|-------|---------|------|
| name | 分类 ID | 显示名称，支持 MiniMessage。 |
| lore | 空 | 分类图标的描述，支持 MiniMessage。 |
| icon | `minecraft:stone` | 分类图标。 |
| priority | 0 | 数值越小越靠前。 |
| hidden | false | 不在主页显示，常用于子分类。 |
| conditions | 无 | 控制分类是否可见。见 [条件](../reference/conditions)。 |
| source | 无 | 提供分类成员的单个源或源列表。 |

`priority` 相同时，按分类 ID 排序。

## 分类源

### list

按顺序添加物品 ID 或子分类引用。子分类 ID 需要以 `#` 开头。

```yaml
source:
  type: list
  list:
    - default:palm_log
    - "#default:topaz"
```

### regex

完整匹配物品 ID，包括原版物品。`regex` 可以是单个表达式或列表。结果先按原版 registry 顺序，再按自定义物品配置顺序排列。

```yaml
source:
  type: regex
  regex:
    - "minecraft:.*_sword"
    - "default:topaz_.*"
```

### all_items

添加全部原版和自定义物品。设置 `ignore_vanilla: true` 后只保留自定义物品。

```yaml
source:
  type: all_items
  ignore_vanilla: false
```

### 组合源

`source` 可以是列表。各源结果按声明顺序追加，不会删除重复项。

```yaml
source:
  - type: list
    list:
      - "#default:topaz"
      - default:palm_log
  - type: regex
    regex: "minecraft:.*_sword"
```

## 旧版格式

仍支持旧版顶层 `list`：

```yaml
categories:
  default:legacy:
    name: "<!i><gray>旧版示例</gray>"
    icon: minecraft:stone
    list:
      - default:palm_log
      - "#default:topaz"
```

## 由物品指定分类

物品可以将自身追加到一个或多个分类：

```yaml
items:
  default:topaz_sword:
    material: golden_sword
    category:
      - default:swords
      - default:topaz
```

这些物品会追加在源结果之后。需要精确顺序时，请使用分类源。
