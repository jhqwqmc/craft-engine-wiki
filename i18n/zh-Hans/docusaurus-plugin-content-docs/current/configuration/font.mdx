## TTF

<UrlCard
  url="https://zh.minecraft.wiki/w/自定义字体#ttf"
  title="TrueType 矢量字体"
/>

使用 TTF 字体时，需要在以下路径创建 `default.json`。如果该文件已存在，请将字体 provider 添加到现有的 `providers` 列表中。

<div style={{textAlign: 'center'}}>
  <img src={require('/img/font_1.png').default} alt="" />
</div>

```json
{
    "providers": [
        {
            "type": "ttf",
            "file": "minecraft:custom_font.ttf",
            "oversample": 10,
            "size": 11
        }
    ]
}
```

</div>
