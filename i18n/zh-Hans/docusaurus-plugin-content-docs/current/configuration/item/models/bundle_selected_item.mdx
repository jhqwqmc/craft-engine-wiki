## 概述

渲染当前在收纳袋中选中的物品。物品必须具有 `bundle_contents` 组件，否则不会显示任何内容。

<UrlCard
  url="https://zh.minecraft.wiki/w/物品模型映射#bundle_selected_item"
  title="Minecraft Wiki | 收纳袋选中物品"
/>

```yaml
items:
  demo:bundle:
    material: bundle
    model:
      type: minecraft:bundle/selected_item
```

此类型**不支持** `transformation`。
