### 取消事件

取消原始事件。

```yaml
type: cancel_event
```

### 运行

按顺序运行一系列函数。这对于共享相同条件的函数非常有用。

```yaml
type: run
delay: 0 # 可选; 数字; 默认值: 0
functions: # 必填; 映射列表
  - type: command
  - type: message
```

### 命令

以玩家、控制台或事件的形式运行命令。

```yaml
type: command
command: "say 你好 <arg:player.name>" # 必填; 字符串列表/字符串
target: "self" # 可选; 枚举[all, self]/玩家选择器; 默认值: self

# 以玩家身份执行这个指令
as_player: false # 可选; 布尔; 默认值: false
# 以op身份执行这个指令，风险自担
as_op: false # 可选; 布尔; 默认值: false
# 有些自定义指令插件基于事件驱动，使用此选项可能可以兼容
as_event: false # 可选; 布尔; 默认值: false
```

### 设置变量

在当前执行上下文中设置变量。之后使用同一个上下文执行的函数，可以通过 [`<var:变量名>`](text_format.mdx#var_变量名_) 读取它。

```yaml
type: set_variable
name: my_variable # 必填; 字符串
value_type: double # 可选; 枚举[int, double, string]
value: 1.0 # 必填（使用 number/text 别名时除外）；int/double 使用数字，string 使用字符串
```

`value_type` 决定变量保存的值类型：

| 值类型 | 保存结果 | 可用值 |
| --- | --- | --- |
| int | 整数；数字结果向下取整 | [数字格式](number_format.mdx) |
| double | 双精度小数 | [数字格式](number_format.mdx) |
| string | 字符串 | 文本；支持 `<arg:...>`、`<var:...>` 等上下文标签 |

`number` 仍可作为数字 `value` 的别名，`text` 仍可作为字符串 `value` 的别名。省略 `value_type` 时，使用 `number` 的配置默认为 `double`，其他配置默认为 `string`。

变量只属于当前上下文，不是全局变量，也不会持久保存。只有后续共享同一上下文的条件、函数和文本渲染才能读取它。

```yaml
type: run
functions:
  - type: set_variable
    name: reward
    value_type: int
    value: "<arg:player.level> / 5"
  - type: message
    message: "<green>你获得了 <var:reward> 枚金币。"
```

### 条件判断

按顺序检查规则，并执行首个满足条件的函数列表。匹配成功后立即停止检查，后续规则即使也满足条件也不会执行。

```yaml
type: if_else
rules:
  - conditions:
      - type: permission
        permission: group.admin
    functions:
      - type: command
        command: say 管理员你好
  - conditions:
      - type: permission
        permission: group.vip
    functions:
      - type: command
        command: say VIP你好
  - functions:
      - type: command
        command: say 玩家你好
```

### 条件匹配

根据源数值进行匹配，并执行首个匹配案例对应的函数。其功能类似于编程语言中的 switch-case 语句

```yaml
type: when
source: <papi:player_world>
cases:
  - when: "world"
    functions: 
      - type: message
        message: "你位于主世界。"
  - when: 
      - "world_nether"
      - "world_the_end"
    functions: 
      - type: message
        message: "你正处于危险维度！"
# 可选配置
fallback:
  - type: message
    message: "你处于未知世界中。"
```

### 转移服务器

将玩家转移到另一个服务器。支持代理插件消息（BungeeCord / Velocity）和 Minecraft 原生 transfer 两种方式。

```yaml
# 代理插件消息 — 按服务器名称（BungeeCord / Velocity）
type: transfer
server: "lobby" # 必填（若未设置 host）；字符串
```

```yaml
# 转移到另一个服务器 — 按主机 + 端口
type: transfer
host: "lobby.example.com" # 必填（若未设置 server）；字符串
port: 25566               # 可选；数字；默认值: 25565
```

### js

调用一个 JavaScript 函数。完整的脚本使用指南见 [<u>📜 脚本</u>](script.mdx)。

```yaml
type: js
script: "mypack:combo"      # 必填; 字符串; 脚本 id（<命名空间>:<不含 .js 的相对路径>）
function: "onRightClick"   # 必填; 字符串; 要调用的函数名
# args - 可选; 列表或 map
# 列表形式：注入为 args 绑定
# args: [ "a", "b" ]
# map 形式：每个键值注入为同名绑定
args:
  combo: "combo_a"
  times: 3
```

:::info
更多函数将在后续版本中加入。
:::
