## 主线程性能分析

Spark 的分析结果有时无法直接反映性能开销的真实来源。部分显示在 CraftEngine 名下的耗时，实际并非由插件本身产生；这是性能分析的归因方式所致，并不是 Spark 的错误。

分析主线程性能时，如果发现疑似来自 CraftEngine 的开销，请先排查以下两类情况。下图示例来自一个同时在线 500 名真实玩家的服务器：

1. **名称以 `Injected` 开头的类（图中红色部分）**

   CraftEngine 会向服务端原有类注入代码以优化特定功能，因此分析器可能把原本属于服务端的部分耗时计入 CraftEngine。

2. **API 调用（图中绿色部分）**

   其他插件通过 CraftEngine API 监听事件或构建物品时，相关耗时也可能被归到 CraftEngine 名下。
