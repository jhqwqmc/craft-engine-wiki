## 开源

CraftEngine 完全开源，所有代码均可公开查看。它的架构为服务端模组化提供了一套参考实现，社区贡献也在持续推动项目发展。

:::info
CraftEngine 是我长期维护的个人项目，并非主要收入来源。插件可供所有人免费使用；如果你需要个人支持，购买付费版也能直接支持后续开发和维护。
:::

## 完善的合成系统

CraftEngine 提供稳定、高效的合成方案，支持几乎所有原版配方类型（地图和烟花合成等少数特殊情况除外），也能与其他插件提供的物品配合使用。

但真正让我们与众不同的是：

- 完全兼容使用物品标签的数据包配方
- 业内最全面的标签支持
- 稳定且高效的配方处理
- 支持对配方结果进行后处理

![](/img/i18n/zh-Hans/recipe.png)

:::tip

想做个小实验吗？

可以尝试在任意其他合成插件中创建一个简单的熔炉配方。设置原料后，先用铁砧将其重命名，再放入熔炉，看看配方能否正常工作。

多数情况下，这个配方会因为 Bukkit API 的限制而失效。

:::

:::caution

如果不需要**超越原版机制**的特殊合成功能，CraftEngine 自带的合成系统通常已经足够。专注于单一功能的插件并不一定更适合所有场景，仍应根据实际需求选择。

:::

## 扩展方块设置

CraftEngine 不仅支持熔岩可燃性、红石导体、地图基色等方块属性，还能定义独特的方块行为。你还可以通过 API 注册新的方块行为类型，开发方式与模组相似。

![](/img/block_behaviors.png)


:::warning

有些插件通过 Bukkit 调度器和事件实现树叶枯萎或方块下落等机制，但这种做法容易产生兼容性和性能问题。

:::

:::tip

你可以组合不同的方块行为，创造新的混合机制。

例如，如果你将“液面方块”与“农作物方块”混合，你就能得到在水面生长的农作物。结合“可下落方块”和“灯方块”，你就会拥有一个能像沙子一样掉落的灯。

:::

## 强大的模板系统

CraftEngine 提供灵活的模板系统。面对结构复杂且高度重复的配置时，可以先创建基础模板，再通过参数批量生成相似配置。

```yaml
templates:
  default:loot_table/crop:
    pools:
      - rolls: 1
        entries:
          - type: item
            item: ${crop_item}
      - rolls: 1
        conditions:
          - type: match_block_property
            properties:
              age: ${ripe_age}
        entries:
          - type: item
            item: ${crop_item}
            functions:
              - type: apply_bonus
                enchantment: minecraft:fortune
                formula:
                  type: binomial_with_bonus_count
                  extra: 3
                  probability: 0.5714286
```

## 全面支持物品模型

CraftEngine 支持完整控制 Minecraft 1.21.4 的物品模型格式。物品可以在物品栏和手持状态下呈现不同外观，也可以根据耐久度或玩家语言切换模型。

:::tip

其他类似的插件通常会将弓、弩和其他物品的配置简化为少数几个纹理选项，这严重限制了你利用高级物品模型功能的能力。

CraftEngine 为弓、弩、三叉戟和盔甲等常见物品提供了预制模板。选择合适的模板并填写参数，即可实现常见效果，同时仍保留进一步自定义的空间。

要充分利用这些功能，需要先理解模板和物品模型的工作原理。相关教程会逐步介绍这些概念及其配置方法。

:::

## 更优的家具实现

CraftEngine 的家具采用实体实现，可以放置在任意位置，不受方块网格限制。无论是细调位置、旋转与缩放，还是将蛋糕准确摆在餐盘上，都可以通过配置完成。
